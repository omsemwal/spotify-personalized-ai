# 👤 Member 8 — Admin Memory Console Frontend

**Folder**: `apps/memory-console/`  
**Assigned To**: Member 8 (Frontend UI Developer)

---

## 🎯 What is this web app for? (Simple Words)
This is the **internal admin console** for engineers and ops to inspect user timelines, test prompt context previewing, and view system performance metrics.

---

## 📝 Simple Steps to Complete
1. **Next.js Admin Setup**: Create admin console app in `apps/memory-console/`.
2. **Timeline Inspector**: Search by user ID and view memory timeline history.
3. **Context Preview Panel**: Enter a test query and preview what context gets composed for the LLM.
4. **Metrics Dashboard**: Display retrieval latency and system health charts.

---

## 🧪 How to Test
- Run `npm run dev` and test looking up a test user ID to view their memory timeline!
