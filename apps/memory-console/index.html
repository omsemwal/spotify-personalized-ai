Memory-enabled vs memory-disabled

The same intent, composed with memory and against the deterministic no-memory baseline.

Three numbers here are honestly unavailable rather than estimated. Precision and recall: the golden cases name synthetic IDs (mem_expected_…) that are not seeded, so there is nothing to score against. Contradiction rate: proving a superseded fact was suppressed needs to read superseded memories, and search only ever returns active ones. Experiment outcomes: no §7.3 endpoint reports cohort results. Everything else on this tab is measured live.
