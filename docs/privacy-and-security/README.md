# docs/privacy-and-security

**What this is:** The privacy and security documentation required by §5.5
and the §11 submission checklist ("Cross-subject isolation and stored-content
prompt-injection tests pass... References... privacy-and-security... included").

## Files
- `policy_registry.md` — human-readable mirror of `packages/policy-engine/registry.py`.
- `threat_model.md` — the threat model from the leadership transcript's
  Security Lead, mapped to concrete mitigations and their test coverage.

See also `tests/security/` for the executable versions of these checks, and
`packages/policy-engine/README.md` for the enforcement code itself.
