# docs/architecture

**What this is:** The system architecture reference. Spec ref: §6 Technical
Architecture.

## Files
- `pipeline.md` — end-to-end Mermaid data-flow diagram (capture → queue →
  processing → graph/vector → retrieval → context → response).
- `overview.md` — the architecture narrative in plain text, mapped 1:1 to
  §6.1's 8 numbered steps, plus the technology choice table from §6.2.
- `LEAD_TASKS.md` — **internal team planning notes** (sprint assignments,
  local file paths from the original author's machine). Not a graded
  deliverable — kept for the team's own reference; a reviewer should look at
  `overview.md` and `pipeline.md` instead.
