# docs/api

**What this is:** Human-readable reference for all 10 required REST endpoints
(§7.3), with example requests/responses and the shared error-code conventions.

For machine-readable schemas of the request/response bodies themselves, see
`data/schemas/` (generated from `packages/contracts/`).

For the 5 MCP tools, see `services/memory-mcp-server/README.md`.
